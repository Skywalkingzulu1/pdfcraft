POV portable mode

While this file sits next to pov.exe, POV keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the POVData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move POV with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\POV and
%LOCALAPPDATA%\POV) instead. If POVData can't be written (for example on a read-only
drive), POV says so and uses the per-user folders instead.
